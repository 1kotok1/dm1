1. запустить опен сервер
2. открыть корневой каталог
3. создать папку 12.local в папке home
4. нажать на папку 12.local правой кнопкой мыши -> "Открыть в Git Bash"
5. в открывшейся консоли автоматически прокладывается путь к этой папке, просто написать git init
6. в папке 12.local создать папку .osp
7. в папке .osp создать файл project.ini, в нем пишем [12.local] php_engine = PHP-8.2 (версия которая горит зеленым в модуле)
8. открываем localhost -> phpMyAdmin
9.  Импортировать базу данных, my_db(1).sql и скачать er диаграмму
10. er диаграмму помещаем в свою папку
11. на этом этапe уже можно сделать первый коммит
git init
git add * login.php
git commit -m "login"

12. дальше как удобнее, можно написать код для всех файлов и сделать коммит.
13. меняем цвет/контрастность/яркость (что угодно) и обрезаем все изображения в GIMP или figma, которые хотим использовать на сайте. главное чтобы было сильно заметно что изображения отличаются внешне от тех которые в зип файле. у меня 4 в слайдере и 1 логотип, его вставила на каждой странице в шапке и в подвале
